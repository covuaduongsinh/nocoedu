# NocoEdu (training management)

Business code of the club's training system. Read this before changing students, classes, attendance or tuition.

- **Data owner.** NocoEdu owns student and parent data. Other apps read it only through `GET /api/ext/*` with an API key of a service account that holds nothing but `edu_api_doc` (`server/routes/edu-ext.ts`). Never add a write there; never return more than a student code, a short name, the level, the class and a parent code.
- **Child data.** Only a birth year, never a date of birth; no photo, school or address. Seeds, tests and logs use made-up names ("Học viên Mẫu 01"). A CSV import prints counts and reasons, never names or phone numbers.
- **Where things are.** Collections `edu*` in `database/main/migrations/202611090001_create_edu_tables.ts` (dates are `YYYY-MM-DD` text, times `HH:mm`, months `YYYY-MM`; booleans are written `true`/`false` so SQLite and Postgres behave the same). Business actions and the fields they read or write: `server/edu/permissions.ts`. Data scopes: `server/edu/record-access.ts`. Routes: `server/routes/edu-*.ts`. Pages: `client/pages/edu/`. Copy in three languages: `client/locales/edu-copy.ts` (Vietnamese is the default).
- **Permission sets** are seeded once and never assigned to anybody. They live twice: `database/seed-data/edu-permission-sets.ts` (source) and the literal in `database/main/seeds/202611090002_edu_permission_sets.ts`, because a seed cannot import application code. After changing the source run `pnpm exec tsx scripts/generate-edu-permission-seed.mts`; `tests/server/edu-permission-sets.test.ts` fails when they differ. Once the seed has run on a database, change it with a new seed, not by editing this one.
- **Routes.** Every route has `auth.required()` and an explicit composite-action check; guards are installed on the route's own paths, never `router.use('*')` (an unrelated path would answer 401 instead of 404; `tests/server/app-server.test.ts` catches it). Standard Repository writes (`createOne`, `updateOne`, `deleteOne`) need an `Idempotency-Key` header; the business routes under `/api/hocVien/...`, `/api/phuHuynh/...`, `/api/dongY/...` do not.
- **Record scopes** that depend on a row of the request itself (a student's `coSoId`, a class's `hlvId`) must filter on that column, not on ids fetched earlier in the request, or a row created in the same request is out of scope.
- **Ids** are auto-increment integers; `ma` (HS00001, PH00001) is the stable code shared with other apps.
- **Tests** run one file at a time: `pnpm exec vitest run tests/server/edu-scope.test.ts`. They share one application per file, so each case resets the school with `seedSchool` in `tests/helpers/edu.ts`.
